## 🎨 About
This project is a **visual redesign only** of the original `ox_target`.

- No core functionality changes  
- Fully compatible with existing systems  
- Focused on **modern UI/UX improvements**  

---

## ✨ Design Highlights
- Modern and clean interface  
- Smooth **circular animation style**  
- Improved visual feedback  
- Better overall user experience  
- Clean and minimal look  

---

## ⚠️ Important
- This is **only a redesign**, not a full rewrite  
- Requires original **ox_target** to work  
- Make sure you have ox_target properly installed  

---

## 📦 Installation
1. Download or clone this repository  
2. Replace "web" folder in `ox_target` with this folder, that you downloaded here
3. Restart your server
